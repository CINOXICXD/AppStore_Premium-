# 🎮 Game & Software Hub

A modern website where users can browse Games, Software, and Subscription plans.

## 🌐 Website Sections

### 🎮 Games
- Games ka separate section hoga
- Har game ka:
  - Name
  - Image
  - Description
  - Size
  - Version
  - Download button

### 💻 Software
- Software par click karne par **saare available software** dikhenge.
- Main baad me apne software add karunga.
- Har software ka:
  - Name
  - Logo/Image
  - Description
  - Version
  - Size
  - Download button

### ⭐ Subscription
- Free Plan
- Basic Plan
- Premium Plan
- Monthly / Yearly subscription
- Subscribe button

## 🔍 Features

- Search bar

- Subscription page

- Responsive design
